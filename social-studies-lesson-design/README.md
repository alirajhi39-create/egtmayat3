# درس تفاعلي: تأسيس الدولة السعودية الثانية

الدراسات الاجتماعية — الصف السادس الابتدائي — الوحدة الثالثة / الدرس السابع.

## المزايا
- ١٤ شريحة تفاعلية مطابقة للكتاب المدرسي + تقويم من ٨ أسئلة.
- استراتيجيات تعليمية ظاهرة في كل شريحة (العصف الذهني، البطاقات المقلوبة، الخريطة الذهنية، فكر-زاوج-شارك، المطابقة، التدريس التبادلي…).
- مؤثرات صوتية + تعليق صوتي عربي، **قابلة للاستبدال بملفاتك الصوتية**.
- تسجيل دخول الطالب باسمه وفصله.
- لوحة معلم: متابعة تقدم كل طالب، إجاباته الكتابية، درجاته، وتصدير Excel/CSV.
- قاعدة بيانات **Neon (Postgres)** عبر دوال **Vercel**، مع وضع محلي احتياطي.

---

## ١) النشر على Vercel

```bash
npm i -g vercel
vercel          # ربط المشروع
vercel --prod   # نشر الإنتاج
```
أو ارفع المشروع إلى GitHub ثم **Import Project** في Vercel (سيكتشف Vite تلقائياً).

### إصلاح خطأ النشر `invalid_function_runtime`
كان `vercel.json` يحدد نسخة runtime للدوال (`@vercel/node@3`) وهذا غير مقبول في Vercel CLI 65.
تم حذف قسم `functions` و`rewrites` بالكامل، وأصبح Vercel يكتشف دوال `api/*.ts` تلقائياً كـ Node Functions.
أعد النشر الآن: **Deployments → ⋯ → Redeploy** (بدون Build Cache).

## ٢) ربط قاعدة بيانات Neon

1. أنشئ مشروعاً مجانياً على <https://neon.tech> واحصل على **Connection String**:
   `postgresql://user:password@ep-xxxx.region.aws.neon.tech/neondb?sslmode=require`
2. في Vercel: **Project → Settings → Environment Variables** أضف:

| المتغير | القيمة |
|---|---|
| `DATABASE_URL` | رابط اتصال Neon |

3. أعد النشر (Redeploy). يُنشئ النظام الجدول تلقائياً عند أول طلب:

```sql
CREATE TABLE lesson_progress (
  id TEXT PRIMARY KEY, student_name TEXT, class_name TEXT,
  lesson_slug TEXT, max_slide INT, total_slides INT,
  quiz_score INT, quiz_total INT, activities JSONB,
  started_at TIMESTAMPTZ, updated_at TIMESTAMPTZ
);
```

> أسرع بديل: من داخل Vercel افتح **Storage → Create Database → Neon**، وسيضيف `DATABASE_URL` تلقائياً.

**بدون قاعدة بيانات** يعمل الدرس كاملاً ويحفظ البيانات والأصوات في متصفح الجهاز فقط، وتظهر في اللوحة علامة «وضع محلي».
لتعمل الأصوات على جميع الأجهزة يجب إضافة `DATABASE_URL`؛ يُنشئ النظام جدول `lesson_sounds` تلقائياً:

```sql
CREATE TABLE lesson_sounds (
  key TEXT PRIMARY KEY,
  mime TEXT NOT NULL DEFAULT 'audio/mpeg',
  file_name TEXT,
  size INT NOT NULL DEFAULT 0,
  data BYTEA NOT NULL,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

> الحد الأقصى لرفع الملف هو ٤ ميجابايت (قيود Vercel). لملفات أطول، صدّر التسجيل بجودة ٦٤ kbps لتقليل الحجم.

## ٣) لوحة المعلم
- الدخول من زر **👨‍🏫 دخول لوحة المعلم** في شاشة البداية، أو أيقونة 👨‍🏫 في شريط الدرس.
- تتطلب لوحة المعلم إدخال رمز الدخول، دون عرض الرمز أو تلميحات له على شاشة الدخول.
- تُحدَّث البيانات تلقائياً كل ١٥ ثانية.
- **🗑️ حذف** بجانب كل طالب لحذفه وإجاباته (مع رسالة تأكيد)، و**🖨️ تقرير** لطباعة تقرير الطالب وحده.
- **📄 طباعة بدون الأسئلة**: تقرير مختصر لا يتضمن إجابات أسئلة التقويم (يبقى جدول التقدم والدرجات). يوجد زر مماثل بجانب كل طالب.
- خياران لمحتوى التقرير: **إجابات الأنشطة** و**أسئلة التقويم وإجاباتها** — يمكنك إيقاف أيٍّ منهما.
- **🖨️ طباعة التقرير PDF**: تقرير رسمي لكل الطلاب (أو لفصل محدد عبر مرشح الفصل) فيه ملخص الفصل وجدول التقدم والدرجات وإجابات الأنشطة. في نافذة الطباعة اختر **الوجهة: حفظ كـ PDF**.

## ٤) استبدال الأصوات بملفاتك
من لوحة المعلم → تبويب **🎙️ إدارة الأصوات**:
- **المؤثرات**: نقرة التنقل، قلب البطاقة، كشف المعلومة، إجابة صحيحة، إجابة خاطئة، نجاح.
- **التعليق الصوتي**: ملف مستقل لكل شريحة من الشرائح الـ١٥ (سجّل شرحك بصوتك).
- **أصوات أسئلة التقويم:** ملف مستقل **لكل سؤال من أسئلة التقويم الثمانية** (`السؤال ١` … `السؤال ٨`).
  - يظهر زر «🔊 استمع للسؤال» مع كل سؤال في التقويم، ويُشغّل ملف السؤال الحالي تلقائياً عند الانتقال بين الأسئلة.
- **تخزين سحابي:** كل ملف يُرفع إلى قاعدة بيانات Neon (`lesson_sounds`) عبر `api/sounds.ts`، لذا يسمعه الطلاب على **جميع الأجهزة**، مع نسخة محلية (IndexedDB) لتشغيل أسرع.
- يبدأ تشغيل الملف السحابي مباشرة دون انتظار تنزيله كاملاً؛ تُهيَّأ أصوات الشريحة الحالية والتالية في الخلفية، وكذلك السؤال الحالي والتالي في التقويم. تدعم واجهة الأصوات طلبات Range لمتصفحات الجوال، وتستخدم روابط بإصدار الملف لتخزين الصوت على CDN دون تشغيل نسخة قديمة بعد الاستبدال.
- عند الانتقال إلى شريحة أو سؤال آخر، أو بدء ملف أو مؤثر جديد، يُوقف المشغّل الصوت السابق وطلبات تشغيله المعلّقة. تُحدَّث قائمة الأصوات عند العودة للصفحة وخلال الدرس دورياً.
- الصيغ المدعومة: MP3 / WAV / M4A / OGG — **الحد الأقصى ٤ ميجابايت للملف**.
- شارة لكل ملف: **☁️ على كل الأجهزة** أو **📱 هذا الجهاز فقط**.
- زر **🔄 مزامنة الملفات المحلية** يرفع الملفات القديمة التي رُفعت قبل تفعيل السحابة.
- الحذف يزيل الملف من السحابة ومن الجهاز معاً.

### مفاتيح ملفات الأسئلة
| السؤال | المفتاح |
|---|---|
| التقويم — السؤال ١ | `voice-slide-13-q1` |
| التقويم — السؤال ٢ | `voice-slide-13-q2` |
| … | … |
| التقويم — السؤال ٨ | `voice-slide-13-q8` |

### بديل: أصوات ثابتة مع المشروع
ضع الملفات في `public/audio/` ثم اربطها بالمفاتيح: `sfx-click`, `sfx-flip`, `sfx-reveal`, `sfx-correct`, `sfx-wrong`, `sfx-success`, و`voice-slide-0` … `voice-slide-14`.
